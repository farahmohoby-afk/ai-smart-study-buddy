# ai-smart-study-buddy
AI Smart Study Buddy: paste any study text and instantly get a smart summary of the key points plus an interactive multiple-choice quiz with correct answers and explanations. Powered by Google Gemini API and built with Python and Gradio. Supports Arabic and English. Built for IceHacks 2026.
## Features
- Smart summary of key points
- Interactive multiple-choice quiz with explanations
- Arabic and English support
- Automatic retry when the API is busy

## Run
1. pip install -r requirements.txt
2. export GEMINI_API_KEY="your-key"
3. python app.py
